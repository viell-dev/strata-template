# Security policy for strata-template

## Supported versions

Security corrections are made to the templates and documentation on `main`. Earlier template
revisions do not receive separate fixes. Repositories using copied material decide whether and how
to apply a correction.

## Reporting a vulnerability

Report security-sensitive problems in these templates privately through
[GitHub's report form](https://github.com/viell-dev/strata-template/security/advisories/new). Include
the source revision, affected component, impact, and a reproduction where possible. Use
[public issues](https://github.com/viell-dev/strata-template/issues) for ordinary documentation bugs
and questions.

## Handling reports

viell reviews incoming private reports and determines the appropriate response, including whether a
correction or public disclosure is warranted. No response or fix deadline is guaranteed.
